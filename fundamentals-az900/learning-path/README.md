# 📚 Azure Fundamentals Learning Path

This directory contains the complete Microsoft Learn learning path for the Azure Fundamentals (AZ-900) certification.

Each learning path is organized into modules, and each module contains the corresponding sections with study notes, summaries, and practical examples.

## Learning Paths

- [ ] 01. Introduction to Cloud Infrastructure: Describe Cloud Concepts
- [ ] 02. Describe Azure Architecture and Services
- [ ] 03. Describe Azure Management and Governance
- [ ] 04. Apply Azure Skills in Guided Projects
