# ☁️ Introduction to Cloud Infrastructure: Describe Cloud Concepts

The first learning path of the Microsoft Azure Fundamentals (AZ-900) certification.

This learning path introduces the fundamental concepts of cloud computing, including cloud models, the shared responsibility model, and the consumption-based pricing model.

---

## Learning Outcomes

After completing this learning path, you will be able to:

- Explain the fundamentals of cloud computing.
- Describe the shared responsibility model.
- Compare cloud deployment models.
- Explain the consumption-based pricing model.
- Build a solid foundation for Microsoft Azure services.
