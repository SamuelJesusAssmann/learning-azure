## About

This directory contains my study notes, documentation, and learning resources for the Microsoft Azure Fundamentals (AZ-900) certification.

The content is based on the Microsoft Learn learning path and is expanded with personal notes, practical examples, and study materials created throughout the learning process.

## Learning Outcomes

- Understand core cloud computing concepts.
- Learn the fundamentals of Microsoft Azure.
- Explore Azure services and architecture.
- Study Azure management and governance.
- Prepare for the Microsoft AZ-900 certification exam.

## Learning Path

Azure Fundamentals is divided into four learning paths designed to build a solid foundation in Microsoft Azure.

1. **Introduction to Cloud Infrastructure: Describe Cloud Concepts**
2. **Describe Azure Architecture and Services**
3. **Describe Azure Management and Governance**
4. **Apply Azure Skills in Guided Projects**
